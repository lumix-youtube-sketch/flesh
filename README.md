# News RSS Bot

Бот для получения новостей по выбранным категориям.

## Как запустить:

1. Открой файл `.env` и замени `ТВОЙ_ТОКЕН_ТУТ` на реальный токен от @BotFather.
2. Открой терминал в этой папке (`news-rss-bot`).
3. Запусти бота командой:
   ```bash
   node index.js
   ```

## Как пользоваться:
- Напиши боту `/start`.
- Выбери категории (нажимай на кнопки, чтобы появились галочки).
- Нажми "Готово".
- Чтобы не ждать 10 минут (стандартный цикл проверки), напиши `/check` — бот сразу проверит RSS-ленты и пришлет самое свежее, если оно появилось с момента последнего запуска.

## Особенности:
- **Красивая верстка:** Используется HTML-парсинг.
- **Картинки:** Бот автоматически пытается вытащить главное изображение из статьи.
- **Память:** Все настройки сохраняются в файл `db.json`, ничего не пропадет при перезагрузке.
